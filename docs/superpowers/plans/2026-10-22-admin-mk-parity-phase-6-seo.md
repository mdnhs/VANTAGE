## Controller calls (my decisions)

1. **Per-page SEO = one versioned global per public page**, keys `seo.page.home|services|our-work|insurance|about|process|contact|get-a-quote`, access `seo.read`/`seo.update` (MK edits page SEO under the `seo` permission, separately from page copy). No new table, API or cache plumbing. Absent row = defaults = today's metadata.
2. **No record-level SEO tabs.** Spec §2.5 asks for them on services/projects detail records "where pages exist"; VANTAGE has no public `/services/<slug>` or `/our-work/<slug>` route, so there is nothing to describe. Also no automatic slug-change redirects (MK's article/page auto rows): table has no `articleId`/`pageId`, UI has no "Automatic" badge.
3. **Where the SEO tab lives:** Home page (`HomePageTabs` gains `seo`), Services/Our work/Process (`PageTabs` gains `seo`), Insurance/About (wrapped in `PageTabs` `content` + `seo`). Contact and Get a quote have no editor → `/dashboard/seo/pages/[id]` (works for all eight ids). The tab is rendered only when the actor has `seo.read`; read-only without `seo.update` or in View-as.
4. **Redirect sources may not be a live page or reserved path** (code routes cannot be unpublished, so MK's "shadowed/inactive while live" state cannot happen; the write is refused: "That address is a live page"). This is what lets the proxy skip live paths with zero cost.
5. **Proxy** follows MK (loopback resolver, 300 ms timeout, fail open, keep visitor query unless destination has its own, same-origin destination check, draft cookie bypass) with two adaptations: live/reserved paths short-circuit in-process; no "missing → 404 rewrite" (Next already 404s unknown code routes). Adds MK's `X-Robots-Tag: noindex, nofollow` on `/dashboard*` and `/login` responses.
6. **Share images:** `src/app/opengraph-image.tsx` is moved to `src/app/og/route.tsx` (same 1200×630 "Vantage" card). Reason: file-based metadata beats `generateMetadata` (`generate-metadata.md` line 114), so today the admin-set default share image is silently ignored. Every page now sets `openGraph.images` explicitly: page image → `seo.defaultOgImage` → `/og`.
7. **`SITE_ENV`** replaces the `VERCEL_ENV === 'production'` test in `robots.ts`: `siteEnv() = SITE_ENV ?? (VERCEL_ENV === 'production' ? 'production' : 'development')`. Without it the VPS build (§5.8) would publish `Disallow: /`. Read at build/prerender time (robots stays `○`).
8. **`internalOrigin()`** = `INTERNAL_ORIGIN ?? (process.env.VERCEL ? new URL(NEXT_PUBLIC_APP_URL).origin : \`http://127.0.0.1:${PORT ?? 3000}\`)`— loopback on the VPS, public origin while still on Vercel (the`/api` path is outside the proxy matcher, so no recursion).
9. **Titles keep today's output in the default state:** template = `seo.titleTemplate || '%s | <site.name>'`; home = SEO title or `<site.name> — Precision Crash Repair & Restoration Dublin` (home ignores `defaultTitle`, as today). Descriptions: own → (home: `seo.defaultDescription` → registry text; other pages: registry text). Registry title/description values are copied verbatim from each page's current `metadata`.
10. **H1 and internal-link checks** (MK reads blocks; VANTAGE pages are code): registry `hasH1: true` for all eight (browser exit check confirms exactly one `<h1>`), internal links = registry `codeLinks` (count of in-page links to other site paths, excluding header/footer; implementer counts them per page, each ≥ 1) + internal `href`s inside the page's `page.*` global value.
11. **Alt text:** images "on the site" = media rows referenced by the eight pages: `page.*` global refs plus the public list queries' rows (home: enabled catalog icons, enabled partner logos, featured published testimonial avatars, featured published project before/after; services: enabled service icon/image; our-work: published project before/after + gallery). Missing = image MIME, `alt.trim() === ''`, not decorative, not deleted — identical to the library's `missingAlt` filter, so "Find images without alt text" agrees.
12. **JSON-LD (MK placement):** home → `@graph` [WebSite, business]; every other public page → [BreadcrumbList Home › page]. Root layout's Organization + WebSite scripts are removed (they also leaked into admin pages). Business `@type` enum `AutoBodyShop` (default) | `AutoRepair` | `LocalBusiness` (MK's `ProfessionalService` does not fit a body shop).
13. **Verification codes** are the token only (`^[A-Za-z0-9_-]*$`, ≤ 100), rendered as `google-site-verification` and `msvalidate.01`.
14. No SEO notifications (MK has none); no AI changes beyond swapping `seoHealth` to the real report.
