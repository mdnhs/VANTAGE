# SEO Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the code-side SEO gaps found in the 2026-11-11 audit of autopaintshop.ie.

**Architecture:** Small, independent edits to the SEO helpers under `src/lib/seo`, the llms.txt query and the legal-page metadata. Business-schema additions are optional admin settings (schema-driven admin UI), never hard-coded. Data-only fixes (address, hours, "Vantage" in the process H1) are admin work, listed at the end, not code.

**Tech Stack:** Next.js 16, zod globals (`src/lib/content/globals.ts`), schema-dts JSON-LD, Vitest.

**Spec:** the audit report in the chat of 2026-11-11 (sections 2 and 3); no separate spec file.

## Global Constraints

- Insurance stays hidden: `INSURANCE_ENABLED` in `src/lib/features.ts` is `false`; nothing insurance-related may appear in SEO output (llms.txt, meta descriptions, JSON-LD).
- Commit headers at most 100 characters; every commit ends with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Never `git push` without the user's explicit go-ahead in that turn.
- Admin text is stored per-site: changing a zod default does not change already-saved values.
- Run `npx tsc --noEmit`, `npx eslint <paths> --max-warnings=0` and the Vitest files named in each task. 14 auth tests fail on main already (`fresh-session`, `session`); ignore them.

## Review Focus

- A saved admin override containing the word "insurance" must still be hidden in llms.txt and meta (filter at render, not only in defaults).
- Optional schema fields left empty must emit no key at all (no `geo: {}`, no `aggregateRating` with 0).
- A rating without a review count must not be emitted (Google rejects it).
- Legal page with a heading-only or very short body must still get a sensible description.
- `default-parity.test.ts` pins default titles and descriptions: changing a default means updating that test on purpose.
